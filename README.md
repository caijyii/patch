# 小贴 · Patch

**截图、长截图、录屏、标注、贴图，一个 Patch 就够。**

一款原生 macOS 工具，把常用的屏幕记录与桌面参考功能放在一起，减少在多个应用之间切换。

## 功能

- **截图**：框选、窗口或整屏截取，复制或保存。
- **长截图**：自动或手动滚动拼接，完成后复制或标注。
- **录屏**：区域录制，可分别开启系统声音和麦克风，导出 MP4。
- **标注**：箭头、形状、文字、画笔、马赛克与原创贴纸，支持在长图和图片贴图上直接编辑。
- **贴图**：把图片或可编辑文字贴在桌面上，随时对照、隐藏或恢复。
- **文字识别**：提取截图中的中英文文字。
- **主体截图**：识别图像主体，导出透明 PNG。
- **自定义快捷键**：在主页为每项功能设置最多两组快捷键，并排显示；已保存的组合暂时不可用时保留设置，并以橙色轻提示。

内容在本机处理，无账户、广告或云上传。

[Preview 5 更新说明](docs/preview-5-release-notes.md)

Preview 5 更新了「剪贴记录」和首页「更多设置」：运行期间自动收录剪贴板图片、纯文本及 Finder 复制的视频文件，也收录 Patch 成功保存的录屏。文字最多 100 条／8 MiB，图片最多 20 条／128 MiB，视频最多 5 条／8 MiB 引用与缩略图预算，各类独立淘汰最旧记录；图片预算计入解码像素、PNG 和缩略图，可能在条数达到上限前触发。历史只在本次运行期间保存，退出后清空。

记录按「今天／昨天／具体日期」展示，可按「全部／图片／文本／视频」筛选。点击图片或文字卡片贴出，点击视频卡片用默认应用播放；每条记录都有直接复制和删除按钮，视频复制为文件。视频仅保留原文件引用和缩略图，不额外缓存完整视频；原文件被移动、删除或无法访问时会提示重新复制。删除或清空历史不会删除原视频文件。「清空」只移除当前选中分类的记录，计数随分类更新。批量贴出只取最近的图片与文字，默认 5 条，可在更多设置中调整为 1～20 条，不受历史面板筛选影响。新贴图出现在光标附近。外观支持跟随系统、浅色、深色，手动选择会记住。

贴图及其工具栏可加入其他应用的全屏桌面，选中贴图、编辑文字或进行内嵌标注时不主动将 Patch 切到前台。

截图选区使用非激活浮层，避免打开或点击时将其他应用的全屏桌面切回 Patch 所在桌面。

图片贴图保留原图宽高比：小图保留原显示大小，大图初始等比缩小到当前屏幕可用宽、高的一半以内；双指滑动、鼠标滚轮和捏合均可缩放，放大后拖动整张图查看，不使用内部滚动条。不透明图片使用小圆角和细边线，透明抠图不增加边框。缩放和圆角只改变显示，复制、保存和提取文字仍使用原始像素。文字贴图采用中性底色、小圆角和细边线，正文 16 pt，初始窗口同样不超过屏幕宽、高的一半；提取文字的结果页正文为 14 pt。截图及贴图操作栏在 1× 显示器使用较大的图标和点击区，在 2× 显示器保留紧凑尺寸，并按可用空间换行。

界面支持简体中文和英文，默认跟随系统（其他系统语言使用英文）。可在「更多设置」选择语言，下次启动生效；截图和剪贴板中的原始内容不会被翻译。

Preview 4 的图案贴纸默认按动物、小黄脸、天气、草叶、花朵和其他图案排列，新增蓝猫紧随小猫。在「更多」面板中拖拽可调整顺序，32 个图案按 8 列、4 行展示；工具栏按可用宽度显示顺序靠前的图案。顺序保存在本机，重启后继续使用，新增图案会插入默认相邻位置并保留已有自定义顺序。普通图片与文字贴图、标注编辑窗口采用细边框和柔和阴影，透明主体贴图保留透明轮廓。隐藏全部贴图后，单独贴出或批量贴出新内容不会恢复之前隐藏的贴图；再次隐藏后，「显示全部贴图」只恢复最近一次隐藏的那组，并保留窗口位置，更早隐藏的组继续保持隐藏。删除或清空剪贴记录不会关闭已经贴出的图。

Preview 4 录屏在保存位置和权限确认后倒计时 3 秒，支持暂停和继续，暂停时间不计入最终视频。倒计时与录制期间保留区域边框和外部轻蒙版，鼠标操作可穿透，控制窗与范围提示均从视频中排除。隐藏控制窗会继续录制，此时可从菜单的「显示控制窗」恢复；点击控制窗左上角关闭会停止并保存，成功后不再弹回。录制期间使用 macOS 自带的菜单栏录屏控件停止录制；Patch 主图标打开功能菜单，菜单内仍可停止、暂停或继续。暂停后的片段会合并成一个 MP4，成功保存前保留原始片段；保存失败会重新显示控制窗以便重试。

## 安装

需要 **macOS 15+、Apple Silicon（M 系列芯片）**。

- **直接下载**：[GitHub 预览版](https://github.com/caijyii/patch/releases/tag/v0.1.0-preview.5)，提供 **DMG / ZIP**，打开 DMG 或解压 ZIP 后，将 `Patch.app` 拖入「应用程序」。无需开发工具。
- **让 Agent 安装**：把下面这句话交给自己的 Agent。

> 请从 https://github.com/caijyii/patch 的 GitHub Releases 下载适合我的 Mac 的 Patch 安装包并安装。

当前为临时签名、未公证的预览包，首次打开可能需要你在系统设置中确认。[安装与权限说明](docs/install.md)

### 从源码构建

开发者需安装支持 Swift 6 的 Xcode 或 Command Line Tools，在项目目录运行：

```sh
bash scripts/build-sandbox-app.sh
```

构建结果：`.build/distribution-check/Patch.app`（Patch Development）。这是临时签名的本地开发包，请避免与其他 Patch 版本同时运行。详见[构建与签名说明](Distribution/README.md)。

使用时请注意：

- 按需授予屏幕、麦克风和辅助功能／设备控制权限；授权未生效时重启应用。
- 长截图保留确认选区的完整范围，可拖动框选或按 `W` 选择窗口。拼接直接使用捕获帧的真实像素，以硬接缝连接，不混合像素或编造被遮挡的内容；固定栏和浮层可能保留或重复。无法可靠定位的一帧不会加入长图，但会继续采样；自动模式会转为手动，可继续滚动，也可随时完成或标注已有结果。动态布局或多滚动容器可能无法可靠拼接。「重新框选」可调整范围，确认新选区后从头开始，按 Esc 保留原结果并返回暂停状态。
- 打开设置、剪贴记录、标注等功能窗口时显示 Dock 图标，关闭所有功能窗口后恢复仅菜单栏运行。最小化窗口会保留 Dock 入口。选择「退出」才会结束应用，贴图只在本次运行期间保留。

## 默认快捷键

以下为Preview 4 的顺序。⌥ 为 Option，⌘ 为 Command，可在主页修改。旧版完整默认配置会迁移到新顺序；自定义配置保留，新增动作遇到占用时会提示冲突，不抢占已有快捷键。

| 快捷键 | 功能 |
| --- | --- |
| ⌥1 | 截图 |
| ⌥2 | 长截图 |
| ⌥3 | 主体截图 |
| ⌥4 | 开始／停止录屏 |
| ⌥5 | 提取文字 |
| ⌥6 | 贴出剪贴板 |
| ⌥7 | 剪贴记录 |
| ⌥8 | 批量贴出最近记录（默认 5 条） |
| ⌥9 | 隐藏／显示全部贴图 |
| ⌘Q | 退出（Patch 位于前台时） |
