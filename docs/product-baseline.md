# Patch 产品与交互基线

## 定位与边界

Patch（小贴）是原生 macOS 屏幕记录与桌面参考工具，将截图、长截图、录屏、标注、贴图、OCR 和主体提取放在一起，减少应用切换。产品定位和功能细节以 [README](../README.md) 为现有公开说明。

当前产品采用本机处理，无账户、广告或自行上传内容的功能；数据与权限的具体边界见 [隐私说明](privacy-policy.md)。涉及云端、历史持久化或后台采集范围的新增需求，需要显式讨论对现有边界的改变，不能作为普通实现细节加入。

本文的“已有约定”整理自现有说明，供后续功能保持兼容；“设计归纳”解释这些行为如何形成体验，不代表已确认的历史动机或永久路线图。修改相关功能时只读对应章节。参数、默认快捷键和发行版本继续由原文档与代码维护。

## 功能如何连接

以下是对已有功能关系的设计归纳：

- **获取内容**：截图、长截图、录屏从屏幕获取信息；剪贴板提供已有图文和视频文件入口。
- **处理与表达**：标注突出信息，OCR 提取文字，主体提取产生透明图像。
- **参考与交付**：贴图用于桌面对照；复制与保存用于交给其他应用；剪贴记录缩短本次运行期间的再次使用路径。

新功能可先说明它服务哪个环节、能否复用已有内容和出口。这里不预先规定职业用户画像，也不据此排除尚未讨论的功能。

## 桌面与窗口

**已有约定**：图片贴图单击选中或开始拖动时激活 Patch，使触控板捏合可用；仅显示图片贴图、文字贴图编辑、内嵌标注和截图选区不主动激活 Patch。切换到其他应用后，捏合前需再次单击图片贴图；滚轮缩放仍可直接使用。贴图及工具栏可出现在其他应用的全屏桌面。普通功能窗口可以激活应用，并在打开期间保留 Dock 入口；最小化也保留，关闭全部功能窗口后恢复菜单栏运行。

**设计归纳**：桌面辅助操作保持用户当前任务连续性；主动进入设置、历史等功能窗口时，使用正常应用窗口行为。“不抢前台”不能扩展成所有窗口都禁止激活。

依据：[README](../README.md)；[WindowActivationCoordinator](../Sources/Patch/WindowActivation.swift)。跨原生全屏 Space 的体验仍需按 [开发说明](../CONTRIBUTING.md) 手动验收，模型测试不能替代真实桌面检查。

## 内容、显示与历史

**已有约定**：贴图缩放和圆角只改变显示，复制、保存和 OCR 仍使用原始像素；长截图使用真实捕获像素，不混合或编造被遮挡内容，允许固定元素保留或重复。长图扩容不得通过降低分辨率、重采样或有损压缩换取长度；预览缩小不影响输出。拼接预算随整机内存分档上升并设封顶，高度另有保护；达到限制时说明是内存预算还是高度上限，保留完整已有结果；本段停止追加，收起“继续”并禁用自动滚动，提示先保存或完成，再从剩余内容开始新一段。

剪贴记录是本次进程的临时历史，图文和视频各有容量边界；视频记录保存原文件引用与缩略图。删除记录不删除原视频，也不关闭已经贴出的图；清空历史不清空系统剪贴板。偏好设置持久化不意味着历史内容持久化。

**设计归纳**：分别定义原始内容、显示状态、历史条目和用户导出文件的生命周期。新增入口或清理操作时说明它作用于哪一层。

依据：[README](../README.md)、[隐私说明的剪贴板、文件和设置](privacy-policy.md#剪贴板文件和设置)；实现入口为 [ImageTools.swift](../Sources/Patch/ImageTools.swift)、[RecentContent.swift](../Sources/Patch/RecentContent.swift)、[ScrollStitcher.swift](../Sources/Patch/ScrollStitcher.swift)。具体配额不在本文复制。

设置中的“截图时隐藏桌面贴图”默认开启，保留原有排除行为；关闭后普通截图与长截图包含当前可见的图片和文字贴图，手动隐藏的贴图不恢复，操作浮层仍排除。设置自动保存，下次截图生效；录屏使用独立的“录屏时隐藏桌面贴图”开关，默认开启，每次录屏开始时固定本次设置，暂停继续不改变；关闭后可录入贴图（含录制中新贴出的图文），录屏控制窗、范围提示及其他小贴功能窗口仍排除。

普通截图与长截图均支持默认悬停识别窗口、单击选择和直接拖动框选。普通截图可沿用选区转入长截图；已有标注时确认清除后重新捕获首帧，取消转换或权限未通过时保留选区和标注。主体选择不提供长截图转换。长截图支持复制、保存、贴图、提取文字及标注，输出使用完整结果；取消保存或导出失败保留结果以便重试。

标注完成后复制完整的标注结果，再退出标注；图片贴图保留更新后的图片并恢复常规贴图状态，复制失败时保留编辑结果以便重试。新建标注不自动选中，切换图案、颜色、粗细、字号或大小默认影响后续标注；主动点选已有标注后，工具栏可修改该对象，支持撤销。图片上的文字标注保留颜色与字号，不提供粗体、斜体。

文字贴图按内容确定宽度，短文收窄，长行在目标屏幕半宽范围内换行，保留原有换行；高度随全文展开，不使用内部滚动条。初次贴出时整张等比适配，含边框的宽、高均不超过目标屏幕可用区域的一半，与图片贴图一致。之后滚轮或捏合缩放整张贴图，不改变换行、字号或复制内容；长文适屏后仍可继续缩小，手动放大后通过拖动查看各部分，编辑时可用工具栏移动手柄或 Option 拖动。编辑内容后重新计算宽高，保留用户当前缩放比例。

文字贴图在“编辑文字”中支持对选中文字调整颜色、字号、粗体和斜体（含中文的实际倾斜），可撤销；未选中文字时这些样式控件禁用。“完成编辑”自动复制整张文字贴图（含样式），成功后恢复常规状态；即使仍有选区也复制全文，失败时保留编辑状态。单独点击“复制文字”仍优先复制选区，无选区时复制全文。复制同时提供纯文本和富文本；默认文字颜色以自动颜色导出，历史内保留随外观适配的默认颜色，避免将深色界面的白字固化到粘贴结果；手动设置的颜色原样保留。从剪贴板贴出时读取可用的 RTF，保留颜色、字体、字号和粗斜体，并保持可编辑。外部来源同样适用；无有效 RTF 时退回纯文本。只保留文字基本样式，不恢复表格、复杂排版或内嵌图片；剪贴记录保存并展示基本文字样式，复制或再次贴出也保留；文字内容或样式变化视为新记录，完全相同的内容与样式继续去重。富文本计入原有文字历史内存预算，不增加持久化。

## 中断、取消与恢复

**已有约定**：长截图无法可靠定位时不加入该帧，继续采样并允许手动滚动或完成已有结果；重选范围确认后才开始新结果，Esc 保留旧结果。录屏隐藏控制窗会继续录制，关闭控制窗会停止并保存；保存失败后保留可重试路径。快捷键暂时不可用时保留配置并提示，不抢占已有自定义组合。

**设计归纳**：错误反馈应说明已有内容是否保留以及下一步能做什么；取消、隐藏、关闭和退出的含义按功能区分，不能统一为“终止并丢弃”。

依据：[README](../README.md)、[Localization.swift](../Sources/Patch/Localization.swift) 中的恢复提示；相关验证入口见 [CONTRIBUTING.md](../CONTRIBUTING.md) 的长截图、录制生命周期和快捷键检查。
