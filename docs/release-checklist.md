2026-11-03，本机已运行试用包的磁盘占用约 2.4 MiB。三次短时 `top` 样本均为 CPU 0.0%、内存约 151 MB、7 线程。此时的使用历史与内存缓存未重置，不是冷启动基线或录屏峰值测试，也不是性能保证。
