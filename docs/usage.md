# 使用说明

[简体中文](usage.md) · [English](usage.en.md)

安装与更新见[安装说明](install.md)，版本变化见[更新说明](release-notes.md)。

## 长截图

- 悬停识别窗口，单击选择；也可直接拖动框选。`R` 切换自由框选，`W` 切换窗口选择。
- 普通截图可从工具栏进入长截图，沿用选区重新捕获。已有标注时会先确认清除，取消则保留原截图。
- 支持自动或手动滚动，可随时完成、保存、贴图、提取文字或标注。无法匹配的帧不会加入结果；自动模式会转为手动，可继续滚动或导出已有内容。
- 「重新框选」确认后从头开始；按 Esc 保留原结果并返回暂停状态。
- 保留原始像素，支持无损 PNG 导出。动态布局或多个滚动区域可能无法可靠拼接，固定栏与浮层可能保留或重复。达到内存预算或高度上限时，先保存当前结果，再开始新一段。

## 桌面贴图

- 图片和可编辑文字可贴在桌面上，也可显示在其他应用的全屏桌面。新贴图出现在光标附近。
- 图片保持比例，大图初始缩小到屏幕可用宽、高的一半以内。用双指滑动、鼠标滚轮或捏合缩放，拖动整张图查看；复制、保存和文字识别仍使用原始像素。
- 捏合前先单击图片贴图激活 Patch；切换到其他应用后需重新单击。滚轮缩放可直接使用。
- 隐藏全部贴图后，新贴出的内容不会恢复旧贴图。「显示全部贴图」只恢复最近一次隐藏的那组，位置保持不变。
- 删除或清空剪贴记录不会关闭已有贴图；退出 Patch 会关闭全部贴图。
- 在主页「更多设置 → 通用」中，可分别设置「截图时隐藏桌面贴图」和「录屏时隐藏桌面贴图」，默认均开启并自动保存。关闭截图隐藏后，普通截图和长截图可包含当前可见的图片、文字贴图；手动隐藏的贴图不会恢复，操作浮层仍被排除。

## 剪贴记录

- 启动时读取当前剪贴板，运行期间自动收录图片、纯文本、Finder 复制的视频文件及 Patch 保存的录屏；没有收录开关，不能识别所有敏感内容。
- 记录仅存于本次进程内存，不写入磁盘，退出后清空。关闭首页仍会在菜单栏继续运行并收录；从 Patch 菜单选择「退出」才会结束。
- 可按图片、文本或视频筛选。点击图片、文字卡片可贴出；点击视频卡片使用默认应用播放。每条记录可直接复制或删除。
- 「清空」只移除当前分类；选择「全部」时才清空全部记录。
- 批量贴出最近的图片与文字，默认 5 条，可在「更多设置」调整为 1～20 条，不受当前筛选影响。
- 视频记录只保留文件引用与缩略图，删除记录不会删除原视频。原文件移动、删除或无法访问时，请重新复制。
- 文字、图片、视频分别最多保留 100、20、5 条；达到各自内存限额时会提前淘汰最旧记录。容量与数据处理详见[隐私说明](privacy-policy.md)。

## 录屏

- 确认保存位置与权限后倒计时 3 秒开始录制。系统声音和麦克风可分别开启。
- 支持暂停和继续，暂停时间不计入视频，最终保存为一个 MP4。
- 隐藏控制窗会继续录制，可从菜单的「显示控制窗」恢复；关闭控制窗会停止并保存。
- 可从 Patch 菜单暂停、继续或停止，也可用 macOS 菜单栏的录屏控件停止。控制窗、范围边框及外部蒙版不会录入视频。
- 关闭「更多设置 → 通用 → 录屏时隐藏桌面贴图」后，可录入可见贴图，包括录制中新贴出的图片和文字；其他 Patch 功能窗口仍被排除。此设置从下一次录制生效，暂停／继续沿用本次设置；它不控制其他录屏应用。
- 保存失败时会保留录制片段并重新显示控制窗，供你重试。

## 贴纸与设置

- 在贴纸「更多」面板中拖动调整顺序，重启后保留；工具栏显示排列靠前且能容纳的图案。
- 外观可选择跟随系统、浅色或深色，选择会保存。
- 界面支持简体中文和英文，默认跟随系统；其他系统语言使用英文。在「更多设置」修改语言后，下次启动生效，原始截图与剪贴内容不翻译。

## 权限与退出

- 屏幕、麦克风及辅助功能／设备控制权限按功能申请；授权未生效时重启应用。
- 关闭首页后仍在菜单栏运行，选择「退出」才会结束应用并清空本次剪贴记录和贴图。
- 功能窗口打开或最小化时保留 Dock 图标，全部关闭后恢复仅菜单栏运行。
