# 使用说明

适用于当前源码；已发布安装包的功能以对应版本说明为准。安装与更新见[安装说明](install.md)。

## 剪贴记录与设置

运行期间自动收录剪贴板图片、纯文本及 Finder 复制的视频文件，也收录 Patch 成功保存的录屏。文字最多 100 条／8 MiB，图片最多 20 条／128 MiB，视频最多 5 条／8 MiB 引用与缩略图预算，各类独立淘汰最旧记录；图片预算计入解码像素、PNG 和缩略图，可能在条数达到上限前触发。历史只在本次运行期间保存，退出后清空。

## 记录操作

记录按「今天／昨天／具体日期」展示，可按「全部／图片／文本／视频」筛选。点击图片或文字卡片贴出，点击视频卡片用默认应用播放；每条记录都有直接复制和删除按钮，视频复制为文件。视频仅保留原文件引用和缩略图，不额外缓存完整视频；原文件被移动、删除或无法访问时会提示重新复制。删除或清空历史不会删除原视频文件。「清空」只移除当前选中分类的记录，计数随分类更新。批量贴出只取最近的图片与文字，默认 5 条，可在更多设置中调整为 1～20 条，不受历史面板筛选影响。新贴图出现在光标附近。外观支持跟随系统、浅色、深色，手动选择会记住。

## 全屏桌面

贴图及其工具栏可加入其他应用的全屏桌面。单击图片贴图或开始拖动时会激活 Patch，使触控板捏合可用；切换到其他应用后，捏合前需再次单击图片贴图。滚轮缩放仍可直接使用；仅显示贴图、编辑文字或进行内嵌标注时不主动将 Patch 切到前台。

## 截图选区

截图选区使用非激活浮层，避免打开或点击时将其他应用的全屏桌面切回 Patch 所在桌面。

## 贴图显示与缩放

图片贴图保留原图宽高比：小图保留原显示大小，大图初始等比缩小到当前屏幕可用宽、高的一半以内；双指滑动、鼠标滚轮和捏合均可缩放，放大后拖动整张图查看，不使用内部滚动条。不透明图片使用小圆角和细边线，透明抠图不增加边框。缩放和圆角只改变显示，复制、保存和提取文字仍使用原始像素。文字贴图采用中性底色、小圆角和细边线，正文 16 pt，初始窗口同样不超过屏幕宽、高的一半；提取文字的结果页正文为 14 pt。截图及贴图操作栏在 1× 显示器使用较大的图标和点击区，在 2× 显示器保留紧凑尺寸，并按可用空间换行。

## 界面语言

界面支持简体中文和英文，默认跟随系统（其他系统语言使用英文）。可在「更多设置」选择语言，下次启动生效；截图和剪贴板中的原始内容不会被翻译。

## 贴纸与隐藏恢复

图案贴纸默认按动物、小黄脸、天气、草叶、花朵和其他图案排列，新增蓝猫紧随小猫。在「更多」面板中拖拽可调整顺序，32 个图案按 8 列、4 行展示；工具栏按可用宽度显示顺序靠前的图案。顺序保存在本机，重启后继续使用，新增图案会插入默认相邻位置并保留已有自定义顺序。普通图片与文字贴图、标注编辑窗口采用细边框和柔和阴影，透明主体贴图保留透明轮廓。隐藏全部贴图后，单独贴出或批量贴出新内容不会恢复之前隐藏的贴图；再次隐藏后，「显示全部贴图」只恢复最近一次隐藏的那组，并保留窗口位置，更早隐藏的组继续保持隐藏。删除或清空剪贴记录不会关闭已经贴出的图。

## 录屏

录屏在保存位置和权限确认后倒计时 3 秒，支持暂停和继续，暂停时间不计入最终视频。倒计时与录制期间保留区域边框和外部轻蒙版，鼠标操作可穿透，控制窗与范围提示均从视频中排除。隐藏控制窗会继续录制，此时可从菜单的「显示控制窗」恢复；点击控制窗左上角关闭会停止并保存，成功后不再弹回。录制期间使用 macOS 自带的菜单栏录屏控件停止录制；Patch 主图标打开功能菜单，菜单内仍可停止、暂停或继续。暂停后的片段会合并成一个 MP4，成功保存前保留原始片段；保存失败会重新显示控制窗以便重试。

## 权限、长截图与后台运行

- 按需授予屏幕、麦克风和辅助功能／设备控制权限；授权未生效时重启应用。
- 长截图保留确认选区的完整范围，默认悬停识别窗口，单击选择，也可直接拖动框选；`R` 切换自由框选、`W` 选择窗口。普通截图框选后也可从工具栏进入长截图，沿用选区重新捕获；已有标注时先确认清除，取消则保留原截图。拼接直接使用捕获帧的真实像素，以硬接缝连接，不混合像素或编造被遮挡的内容；固定栏和浮层可能保留或重复。无法可靠定位的一帧不会加入长图，但会继续采样；自动模式会转为手动，可继续滚动，也可随时完成或标注已有结果。动态布局或多滚动容器可能无法可靠拼接。「重新框选」可调整范围，确认新选区后从头开始，按 Esc 保留原结果并返回暂停状态。
- 打开设置、剪贴记录、标注等功能窗口时显示 Dock 图标，关闭所有功能窗口后恢复仅菜单栏运行。最小化窗口会保留 Dock 入口。选择「退出」才会结束应用，贴图只在本次运行期间保留。
