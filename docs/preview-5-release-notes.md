# Patch 0.1.0 Preview 5

本次更新改善长截图、桌面贴图和剪贴记录，并加入双快捷键。

- 长截图允许固定栏、浮层保留或重复；遇到无法匹配的帧继续采样，已有结果仍可完成或标注。
- 图片贴图保持原图比例，大图默认适配到当前屏幕宽、高的一半以内；支持触控板捏合缩放，复制与保存仍使用原始像素。改进全屏桌面的截图浮层和外接屏操作栏。
- 「显示全部贴图」只恢复最近一次隐藏的那组；删除剪贴记录不关闭已有贴图。
- 剪贴记录增加直接复制按钮，文字、图片、视频分别保留最多 100、20、5 条，并各自受内存预算限制。视频只保存文件引用与缩略图，删除记录不会删除原文件。
- 每项功能最多设置两组快捷键，在原主页中单行并排显示。已保存的组合暂不可用时保留设置并轻提示，另一组可继续使用。
- 更多设置采用紧凑布局，统一提示样式；优化剪贴说明换行、快捷键选中与悬浮样式，以及文字贴图和文字提取结果的字号。
- 标注初始粗细调整为 3.5，贴纸大小为 36，马赛克大小为 8；保留用户已有设置。
- 修复快捷键菜单初始化顺序引起的启动闪退。

安装包支持 Apple Silicon、macOS 15+，提供 DMG 和 ZIP。更新前退出旧版，将新版 Patch.app 放到原安装位置。开发包与发行包的设置、权限分别保存。

本版仍为临时签名、未公证的预览版，首次打开和授权请参照[安装说明](install.md)。动态页面及多个滚动区域不保证都能可靠拼接。剪贴记录在退出后清空。
