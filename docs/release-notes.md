# Patch 0.1.3

[简体中文](release-notes.md) · [English](release-notes.en.md)

本次更新改善标注、文字贴图与剪贴记录的连贯操作：

- 图片标注或文字贴图编辑完成后，自动复制完整结果，再恢复常规贴图状态。
- 新建标注后切换图案、颜色等样式，默认用于下一次标注；主动选中已有标注时，仍可修改该对象。
- 文字贴图的“编辑文字”支持选中文字后调整颜色、字号、粗体和斜体，并支持撤销；修复中文斜体未实际倾斜的问题。图片上的文字标注保留颜色与字号。
- 复制、再次贴出及剪贴记录保留文字基本样式；来自其他应用的有效 RTF 也可贴为可编辑文字。样式变化会形成新记录，相同内容和样式继续去重。
- 修复默认文字颜色在复制后固化为白色的问题，手动设置的颜色保持原样。
- 修复文字贴图缩小异常。短文按内容收窄，长文自动换行并完整展开，不再使用内部滚动条；初始宽、高均不超过屏幕可用区域的一半，之后可整体缩放和拖动查看。

支持 Apple Silicon、macOS 15+。退出旧版前请保存需要保留的贴图；再用新版覆盖原安装位置的 Patch.app。安装包仍为临时签名、未经过 Apple 公证，更新后可能需要重新授权，详见[安装说明](install.md)。

## Patch 0.1.2

本次更新增加贴图捕获选项，并修复后台提示框导致操作看似卡住的问题：

- 通用设置新增“截图时隐藏桌面贴图”和“录屏时隐藏桌面贴图”两个独立开关，默认开启，自动保存。
- 关闭截图隐藏后，普通截图与长截图可包含当前可见的图片、文字贴图；手动隐藏的贴图不恢复，操作浮层仍排除。
- 关闭录屏隐藏后，可录入桌面贴图，包括录制中新贴出的图文；录屏控制窗、范围提示及其他功能窗口仍排除。录屏设置从下一次录制开始生效，暂停继续沿用本次设置。
- 修复从后台触发错误提示时，弹窗未获得前台焦点却阻塞后续操作的问题。提示框现在会激活到前台，关闭后即可继续。

支持 Apple Silicon、macOS 15+。退出旧版前请保存需要保留的贴图；再用新版覆盖原安装位置的 Patch.app。安装包仍为临时签名、未经过 Apple 公证，更新后可能需要重新授权，详见[安装说明](install.md)。

## Patch 0.1.1

本次更新改善长截图的长度和达到上限后的提示：

- 保留原始像素，不降低分辨率；PNG 继续无损导出。
- 拼接预算随整机内存调整，最高从 128 MiB 提升到 512 MiB；高度保护从 20,000 提升到 60,000 像素。实际可截长度仍受选区宽度和内存预算影响。
- 明确区分内存预算、高度上限和选区过大。达到上限后停止本段拼接，收起“继续”并禁用自动滚动，提示先保存或完成，再从剩余页面开始新一段。
- 已拼接结果仍可保存、贴图、提取文字或标注；取消重新框选或取消保存后，保持正确的上限提示。

支持 Apple Silicon、macOS 15+。退出旧版后，用新版覆盖原安装位置的 Patch.app；设置沿用，更新后可能需要重新授权。安装包仍为临时签名、未经过 Apple 公证，详见[安装说明](install.md)。

## Patch 0.1.0

首个正式版本，在 Preview 5 基础上包含以下调整：

- 长截图支持直接保存、贴图和提取文字；标注后的长图也可贴出或提取文字。
- 普通截图可从工具栏进入长截图；长截图默认识别窗口，也可拖动框选。
- 改进图片贴图的触控板缩放交互：单击图片贴图后可捏合缩放，滚轮缩放仍可直接使用。
- 统一主页、设置、剪贴记录、录屏和文字结果窗口的背景光晕。
- 更新 DMG 安装界面，提供应用与 Applications 文件夹的拖放安装入口。

- README、更新说明、安装指南、使用说明和隐私说明均提供中英文版本。

支持 Apple Silicon、macOS 15+，提供 DMG 与 ZIP。正式版标记不改变签名状态：本版使用临时签名，尚无 Developer ID 签名，也未经过 Apple 公证。首次打开与授权步骤见[安装说明](install.md)。

退出后会清空剪贴记录和贴图；动态布局及多个滚动区域可能无法可靠拼接。历史版本见 [Preview 5 更新说明](preview-5-release-notes.md)。
