# 首次源码公开说明草稿

**截图、长截图、录屏、标注、贴图，一个 Patch 就够。**

Patch 的开发初衷，是希望长截图、录屏和贴图能够与日常截图、标注一起，出现在同一个顺手的 macOS 工具里，减少在多个应用之间切换。

此次公开范围为应用源码、原创图稿与生成脚本、合成测试素材、构建和验证脚本。源代码采用 MIT 许可证，版权署名为 caijyii；第三方资源保留各自许可声明。

## 功能范围

- 普通截图、滚动长截图、区域录屏。
- 截图、长图及图片贴图的原位标注。
- 图片与可编辑文字贴图，统一隐藏和恢复。
- 本地中英文 OCR、主体透明导出。
- 自定义快捷键与四季窗景主页。

## 当前发布边界

本次是源码公开准备，尚未发布 App Store 版本。商店定价未定；本地临时签名开发包不等于正式发行包，不作为首次源码上传的下载附件。

最低系统版本为 macOS 15，当前测试以 Apple Silicon 为主。长截图对静态正文更可靠，固定标题栏、动画或重复图案可能影响拼接。最终签名包的干净系统权限验收及真实录屏压力测试仍待完成。

构建方法和验证范围见仓库 README。用户可以报告问题或提交改进；支持邮箱为 caijyii@163.com。仓库为 https://github.com/caijyii/patch ，本次文件范围已由维护者确认。
