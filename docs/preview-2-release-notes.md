# Patch 0.1.0 Preview 2

这一版集中改善截图、录屏和贴图标注的交互。

- 主体截图没有可导出的主体时，双击空白可退出；文字提取的确认／取消增加文字说明，主体截图保留紧凑图标。
- 录屏提供一致的框选／窗口／整屏入口；控制面板随内容收紧，保存位置提示保持单行。
- 长截图与图片贴图的标注画面默认居中、完整适配，支持触控板双指缩放。
- 图片周围空白区也可标注；复制、保存或应用时按原图与标注范围自动扩边补白。没有外部标注时保留原图尺寸。
- 统一标注入口图标与右上角完成按钮；修复复制按钮持续选中、颜色按钮悬浮后色块消失的问题。
- DMG 内附简短安装说明，可直接转发给朋友试用。

## 安装与试用范围

- Apple Silicon（M 系列芯片），macOS 15 或更新版本；暂不提供 Intel 安装包。
- 下载 DMG 后将 Patch.app 拖入 Applications，先退出旧版再替换。无需开发工具。
- 当前为启用应用沙盒的临时签名包，尚无 Developer ID 签名，也未经过 Apple 公证。首次打开与权限设置见 [安装说明](https://github.com/caijyii/patch/blob/main/docs/install.md)。
- 仓库附件需有相应访问权限；维护者直接发给你的 DMG 可本地安装。

## 验证范围与已知情况

本轮包含合成素材的图片渲染、扩边导出、居中与缩放事件、按钮状态、工具栏悬浮、选区、长截图与录屏生命周期回归；这些检查不替代另一台 Mac 上的首次安装和真实录屏验收。

文字识别曾出现一次停留在“识别中”的反馈，随后重试恢复；后台及小图回归通过，但首次停滞的根因尚未稳定复现，本版不宣称已彻底解决。
