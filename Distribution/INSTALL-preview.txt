Patch 预览版安装说明

适用于 Apple Silicon（M 系列芯片）的 Mac，要求 macOS 15 或更新版本。
当前不支持 Intel Mac。安装无需 Xcode 或其他开发工具。

安装
1. 先退出正在运行的旧版 Patch 或 Patch Development。
2. 将这个磁盘映像中的 Patch.app 拖到旁边的 Applications 文件夹。
3. 如果已有旧版，请确认替换目标；请勿同时运行多个版本。
4. 安装后推出磁盘映像，从“应用程序”打开 Patch。

首次启动
这是采用临时签名（ad-hoc）、尚未经过 Apple 公证的试用版本。
若系统提示无法验证开发者，请先确认文件来自你信任的维护者。
如果选择继续，可按 Apple 官方说明，在“系统设置 → 隐私与安全性”中
查看是否提供“仍要打开”，由你本人确认。
https://support.apple.com/102445
若提示恶意软件或文件损坏，请停止安装并反馈，不要关闭系统安全保护。

权限
截图和录屏需要屏幕录制权限；麦克风和长截图控制权限会按功能需要申请。
若授权后仍无法使用，先退出并重新打开 Patch。
更新临时签名版本后可能需要重新授权。

反馈
告诉维护者你的 macOS 版本、Mac 芯片、复现步骤和实际提示即可。
请避免提供包含隐私信息的截图、录音或录屏。
